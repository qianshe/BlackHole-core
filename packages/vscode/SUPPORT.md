# BlackHole Support

BlackHole is published by **qianshe**.

For bugs and reproducible extension issues, use the GitHub issue tracker:

https://github.com/qianshe/BlackHole-core/issues

When reporting a problem, include the BlackHole extension version, VS Code version, operating system, the action you were performing, and the exact error message. Do not include access tokens, payment credentials, private keys, subscription card codes, or workspace secrets.

For payment or account issues, include only the BlackHole order ID or other non-secret identifier needed to locate the record.
