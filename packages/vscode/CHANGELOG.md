# Change Log

## 0.3.195 — 2026-10-03

- **渠道总开关与局域网直连**：VS Code 侧边栏、本地 Web 和设置页新增渠道一键开关，打开时启动上次使用的渠道，关闭时停止所有渠道，缺少前提时会提示去哪里补。daemon 新增局域网直连开关，另一台机器上的 Agent 可以直接通过 MCP 连接；cloudflared 隧道按连接器状态决定是否重连。
- **会话更顺手**：新建会话时第一条消息直接作为任务；Sandbox 改为直连 MCP，并优化了沙箱提示词。会话时间线改为增量推送，消息支持 Mermaid 图和缩放。
- **工作区外文件**：editor 按会话权限访问工作区外的路径，查看图片时直接返回图片内容。
- **设置与启动**：设置页里不需要重启的设置改为自动保存；daemon 端口已被占用但控制面还没就绪时，会延长等待时间，不再误报启动失败。
- **Web 控制台修复**：修复往上翻页后视图跳回顶部的问题；手机端新增「回到底部」按钮，窄屏时会话详情收为右上角图标。
