# Change Log

## 0.3.184 — 2026-09-28

- New local Web console (**BlackHole: 打开本地 Web**): sign in, view sessions, create sessions, manage projects and change settings.
- Phone access (off by default): enable it in Settings, scan the QR code and allow the device on the computer.
- New OpenAI connection channel next to Cloudflare; both can run at the same time.
- Settings and sign-in are now shared by VS Code and the Web console, and move over automatically on update.
- Fixes: garbled Chinese output on Windows, lingering ended sessions, file navigation in symlinked workspaces on macOS. BlackHole is now licensed under Apache-2.0.
