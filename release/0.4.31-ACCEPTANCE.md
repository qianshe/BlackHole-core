## Limits

Community prerelease, not a vendor-certified release. Windows has no Authenticode publisher
certificate; macOS has verified ad-hoc signing and is not Apple-notarized. App-specific first
launch guidance is included in the DMG, Release INSTALL.txt and download page. No global
security-disable instruction is provided.

Interactive native GUI acceptance and macOS Gatekeeper approval by a person were not performed.
macOS/Linux use manual installer replacement for upgrades. Linux packages target Debian/Ubuntu
with WebKitGTK 4.1; RPM/AppImage are not supplied. Marketplace publishing and main-branch merges
are separate from this Desktop release.
