BlackHole Desktop - Community distribution / 社区分发版

macOS
Choose Apple Silicon (arm64) for M-series Macs, or Intel (x64) for Intel Macs.
Open the DMG and drag BlackHole.app into Applications before launching.
This build has an ad-hoc signature, not an Apple Developer ID signature,
and has NOT been notarized by Apple. Gatekeeper may block first launch.
If you trust this official download, attempt to open it, then go to:
System Settings > Privacy & Security > Security > Open Anyway.
Confirm the specific BlackHole app. Availability depends on macOS and device policy.
Do not bypass a malware/revoked-signature alert or globally disable Gatekeeper.
If macOS says the app is damaged, download again and report the exact message.
Apple's instructions: https://support.apple.com/102445

选择与处理器对应的 DMG，将 BlackHole.app 拖入“应用程序”后打开。
此社区版本只有 ad-hoc 签名，没有 Apple Developer ID 签名，也未经过 Apple 公证。
如首次运行被“无法验证开发者”或“Apple 无法检查”拦截，请确认来自官方仓库，
尝试打开一次后，进入“系统设置 > 隐私与安全性”，针对 BlackHole 选择“仍要打开”。
不同系统版本或受管设备可能不提供此选项。
如提示恶意软件、授权被撤销或文件损坏，请停止运行、重新下载或反馈，不要全局关闭系统保护。

Windows
No Authenticode publisher certificate is provided in the community build.
Core and update metadata use BlackHole Ed25519 signatures; these do not
replace an OS publisher certificate or guarantee that software is harmless.

Linux
The .deb targets Debian/Ubuntu-compatible systems with WebKitGTK 4.1.
Install with: sudo apt install ./BlackHole-Desktop-<version>-linux-<arch>.deb
The package manager resolves declared dependencies.
RPM, AppImage and other distributions are not provided by this release.

All platforms
Quit Desktop before replacing its files. Existing shared Core/user data is retained.
macOS/Linux updates are currently manual installer replacement.
Download only from: https://github.com/qianshe/BlackHole-core/releases
Do not treat a successful checksum or signature check as a malware scan.
